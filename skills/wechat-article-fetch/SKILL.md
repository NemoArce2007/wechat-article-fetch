# 微信公众号文章抓取与清洗

将微信公众号文章抓取为 Markdown，并自动清理广告和格式问题。

脚本与本文件同目录：`wechat_article_to_md.py`。缺少依赖时先执行 `pip install -r requirements.txt`（`requests`、`beautifulsoup4`）。

## 工作流

### Step 1 — 抓取转换

在本技能目录执行：

```bash
python wechat_article_to_md.py <文章URL> <用户指定的输出目录>
```

- 检查脚本输出，确认"保存成功"
- 记住生成的文件路径（脚本会打印）

如果用户要求不下载图片：

```bash
python wechat_article_to_md.py <文章URL> <输出目录> --no-images
```

### Step 2 — 智能清洗

读取 Step 1 生成的 Markdown 文件，执行以下清洗：

#### 去广告

识别并**删除**以下类型的广告和噪音内容：

- 文末关注引导（"长按关注"、"扫码关注"、"点击关注"等）
- 二维码相关提示文字和图片引用
- "阅读原文"、"点赞"、"在看"、"分享"等引导语
- "更多精彩内容"、"推荐阅读"后跟的外部链接列表
- 文中或文尾插入的课程推广、产品广告、社群招募
- "限时优惠"、"扫码入群"、"添加微信"等营销话术
- 文末版权声明中的推广信息

#### 修格式

- 修复标题层级（正文从 ## 开始，不应出现与文章标题同级的 #）
- 合并被错误拆分的段落（同一段意被空行切断的）
- 清理连续 3 行以上的空行（保留最多 1 行空行）
- 确保列表、引用、代码块的 Markdown 格式正确
- 图片引用格式统一为 `![描述](images/xxx.png)`

#### 补元信息

确认文件头部包含完整元信息：

```markdown
# 标题

**作者**: xxx
**发布时间**: xxx（如有）
**来源**: https://mp.weixin.qq.com/s/xxx
**抓取时间**: YYYY-MM-DD HH:MM

---
```

#### 内容质量检查

- 检查正文是否有明显截断（结尾突然中断）
- 检查是否有乱码或编码异常
- 如果发现问题，在回复中告知用户

### 清洗原则

1. **只删除，不添加** — 不补充原文没有的内容
2. **宁留勿删** — 边界模糊时保留，宁可留着疑似广告也不误删正文
3. **保持原文风貌** — 不改变语言风格、段落结构、用词习惯
4. **覆写保存** — 清洗完成后覆写原文件，不要新建文件

## 输出位置

输出目录由用户指定。如果用户未指定，询问用户希望保存到哪里。

## 注意事项

- 微信视频无法下载，保留视频位置标记即可
- 部分文章可能有访问限制，脚本会报错
- 图片下载可能受网络影响失败，失败的图片会保留原始链接
